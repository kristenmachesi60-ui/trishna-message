ROMANTIC SECRET MESSAGE - HOW TO USE
===================================

OPEN THE WEBSITE
1. Double-click index.html - it opens in your browser instantly.
   Works on phone, tablet and computer. No internet needed.

HOW IT WORKS
- Visitor enters the secret code on screen 1.
- Correct code -> "OPEN" screen appears.
- Press OPEN -> romantic popup with the message appears.
- She can tap "I LOVE YOU TOO" (shows a happy reply)
  or "I DON'T" (the button runs away - it can't be clicked).
- CLOSE dismisses the popup.

PUBLISH ONLINE (free options)
1. Netlify Drop: go to app.netlify.com/drop, drag this folder in,
   get a free link instantly - share it on WhatsApp.
2. GitHub Pages: upload folder to a GitHub repo, enable Pages.
3. Or just send the ZIP - she extracts it and opens index.html.

FILES
- index.html  - the whole website
- style.css   - all styling & animations
- script.js   - code check + animations
- README.txt  - this file

The secret code is stored in script.js (client-side only).
It is NOT shown anywhere on the welcome screen.
No database, no accounts, no data collected.
